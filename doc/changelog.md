# 更新日志

每个版本的主要变化。**升级** 一行说明除了面板以外还要不要升级节点 agent；没写的只需升级面板，见 [升级](./guide/upgrade.md)。

完整的提交记录见 [GitHub Releases](https://github.com/jacob-bytes/hoplane/releases)。

## 0.7.0

2026-10-30

- **流量趋势**：统计保留 31 天，图表支持 24h / 7 天 / 30 天；按天聚合，旧数据不足时回退到最近 24 小时
- **流量预测**：已用流量卡显示预计用完天数；达到 80% / 95% 时显示提醒
- **审计日志**：新增 `audit_log` 表和只读管理页，记录用户、操作、路径、IP、UA 和时间，支持搜索
- **节点详情**：服务器操作面板增加「详情」，展示实时资源、速率、本月流量、IP、版本、运行时长和续费信息
- **订阅编辑**：订阅表格行增加编辑入口，操作列加宽
- **IP 国家库**：后端镜像内置 GeoLite2-Country（约 3.2 MB，构建时校验 SHA-256），新建/编辑服务器时自动填写国家；也可用 `HOPLANE_GEOIP_MMDB`、`HOPLANE_GEOIP_CSV` 或 `HOPLANE_GEOIP_URL` 覆盖
- **首次使用**：无服务器时概览显示四步引导，可直接跳转添加服务器、安装 agent、配置节点和创建订阅
- **登录与移动端**：登录错误内联显示、密码显隐、移动端安全区；审计页和节点详情在 375px 下保持可用
- **外观精简**：移除自定义背景上传、内置壁纸和主题选择，仅保留纯色背景与亮色/暗色/跟随系统；移除赛博朋克主题

**升级**：只需升级面板，agent 无需变动。

## 0.6.0

2026-10-30

- **会话管理**：JWT 增加 `jti`，新增 `user_session` 表；账户页可查看登录设备、IP、最近活跃时间，并退出单设备 / 其他设备 / 所有设备；被撤销的 token 立即失效
- **流量方向**：每小时统计新增上行/下行增量，24 小时图表在数据可用时切换为上下行堆叠面积；旧数据按当前比例回填
- **续费金额**：服务器表单支持填写续费金额，卡片显示「费用 ¥xx / 周期」
- **规则详情**：规则弹窗改为「常用 / 复制 / 危险操作」分组，增加图标、说明、状态 badge 和紧凑信息区
- **订阅用量**：订阅列表补充百分比和重置周期，进度条填满列宽
- **表格与适配**：入站在无导入节点时隐藏延迟列，有导入节点时显示端口/延迟；配置页默认展开「基本」并缩短 320px Tab 文案；隧道列表增加入口/倍率列；限速规则补充用途说明
- **登录与空态**：登录失败增加表单内错误、密码显示切换和自动填充属性；监控空态改为可执行说明
- **深色模式**：修正国旗描边、图表面积、远程用量子面板等硬编码白/黑样式
- **性能**：服务器列表超过 60 条时按可视区域窗口化渲染，减少长列表 DOM
- **IP 国旗**：支持可选的 `HOPLANE_GEOIP_URL` 自建 IP 国家查询；未配置时继续按名称推断，不会外发节点 IP

**升级**：只需升级面板，agent 无需变动。

- **标识符统一成 Hoplane**：环境变量改成 `HOPLANE_*`，容器与镜像改成 `hoplane-panel-backend` / `hoplane-panel-postgres` / `hoplane-frontend` / `hoplane-agent`，agent 装在 `/etc/hoplane_agent`、服务名 `hoplane_agent`，nftables 表改成 `inet hoplane` 与 `inet hoplane_kernel`，发布资产改成 `hoplane-agent-<arch>`，浏览器本地的主题与缓存键也换成 `hoplane:*`（首次打开会回到默认主题）
- **旧部署仍能启动**：面板与 agent 还认旧的 `FLVX_*` / `FLUX_AGENT_*` 环境变量（含容器模式判断），集成方继续发 `X-FLVX-API-Client` 也照样生效
- **旧痕迹自动清理**：agent 启动时删除旧的 `flvx` / `flvx_kernel` nft 表（否则流量会重复计数、白名单会继续拦端口）；agent 安装脚本停用并删除旧的 `flux_agent` 服务与 `/etc/flux_agent`；面板安装脚本和面板内升级在启动前都会移除旧的 `flux-panel-*` / `vite-frontend` 容器（数据卷是显式命名，不受影响）

**升级**：需要升级 agent，而且建议**重装**而不是就地升级——安装目录、服务名、容器名都变了。面板升级后在 **服务器** 页对每台机器重新生成安装命令执行一遍即可，面板数据、订阅链接、节点配置都不受影响。
