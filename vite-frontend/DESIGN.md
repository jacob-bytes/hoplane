# Hoplane 视觉方向 v3 · 「白底深蓝」

> 在「仪器」的基础上调整：**白底、清晰的深蓝主色、更圆润**，整体参考 shadcn admin 的克制版式。
> 仍然保留：排版优先、等宽数字、一个主操作、动效只服务状态变化。
> Token 以本文为准，落地写进 `src/styles/globals.css` / `tailwind-theme.pcss`。

## 0. 调整后的取舍

| 上一版 | 现在 v3 |
|---|---|
| 暖纸底 `#f4f2ed` | **纯白页面底** `#ffffff`，灰只用于侧栏/表头/弱块 |
| 主操作 = 墨色 | **主操作 = 深蓝** `#1d4ed8`，全站只有一个品牌色 |
| 圆角 4/6/10，偏硬 | **圆角 6/8/12/14**，卡片与弹窗更圆润 |
| 徽章方形 | 状态徽章 **圆角胶囊 + 浅色底**；数据标签保持小圆角 |
| 卡片 hairline 无阴影 | 卡片保持 1px 边，**不加阴影**；只有浮层有阴影 |
| 侧栏左侧竖轨 | 侧栏**圆角选中块**（浅蓝底 + 深蓝字） |

避免的仍然是这些模板信号：紫色渐变、玻璃模糊、彩色图标砖、满屏药丸、5 种字号、无意义的动效。

## 1. 关键词

1. **白纸（White）**：页面是白的，层级靠 1px 线与浅灰块，不靠阴影。
2. **深蓝（Deep Blue）**：一个品牌色用到底——主按钮、选中、焦点、链接、图表首序列。
3. **圆润但不软（Rounded, not puffy）**：6–14px 的圆角；没有 24px 大圆角，也没有全直角。
4. **一点灵动（Alive）**：选中块滑动、行箭头轻移、弹窗 200ms 进入；其余静止。

状态底色（浅色主题）：success `#f0fdf4` / warning `#fffbeb` / danger `#fef2f2`；暗色用 12% 透明叠加。

图表 6 色：`#1d4ed8`、`#0e7490`、`#b45309`、`#15803d`、`#7e22ce`、`#be123c`。

规则：

- 一个页面只有一个主按钮（深蓝实心）；其余用白底描边或幽灵。
- 颜色只出现在按钮、选中块、状态点/徽章、图表；正文永远灰阶。
- 状态不能只靠颜色：点 + 文字。
- 禁止 `#000` / `#fff` 之外的"品牌蓝变体"；不要一个页面出现三种蓝。

## 3. 字体

- UI：**Geist**；数据：**Geist Mono** + `tabular-nums`。
- 中文回退：`PingFang SC` / `Noto Sans SC`。

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 22 / 30 | 600 | 每页一个 |
| 区块标题 | 15 / 22 | 500 | 卡片、弹窗 |
| 正文 | 14 / 21 | 400 | 表格、按钮、输入 |
| 次要 | 13 / 19 | 400 | 说明、meta |
| 标签 | 11 / 16 | 500 | 表头、eyebrow（拉丁加 `0.06em`） |
| 数字 | 13 / 18 mono | 500 | 延迟、流量、指标 |

- 一屏最多 4 种字号。
- 中文标签不加大字距、不做 uppercase。
- 单位小一号、`--muted`：`54 ms`、`1.2 GB`。

## 4. 间距、圆角、阴影

- 间距：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。
- 圆角：**6**（输入、标签）、**8**（按钮）、**12**（卡片、表格容器）、**14**（弹窗）。状态徽章胶囊，数据标签 6。
- 卡片：白底 + 1px `hairline`，**无阴影**。
- 浮层：1px 边 + `0 16px 48px -24px rgb(15 23 42 / .35)`。
- 分隔优先用线，不用色块。

| 场景 | 值 |
|---|---|
| 页面内边距 | 桌面 24，移动 16 |
| 区块间距 | 24 |
| 卡片内边距 | 16 |
| 表格行高 | 密集 40 / 常规 48 |
| 控件高度 | 32 / 36 / 40 |
| 触控目标 | ≥24×24，移动主操作 ≥44 |

## 5. 组件语言

### Button

- 主：深蓝底白字，8px 圆角，36 高，无阴影；hover 深一档。
- 次：白底 + 1px `hairline`；hover 边深、底 `surface`。
- 幽灵：透明底，hover `surface`。
- 危险：白底红字红边；只有确认弹窗的最终按钮用红底。
- 按压 `scale .985`，90ms。
- 一屏一个深蓝主按钮。

### Badge / Chip

- **状态**：胶囊（`rounded-full`），浅色底 + 状态点 + 文字，12px。
- **数据标签**（线路、端口）：`rounded-md`，白底 1px 边，等宽字。
- 计数：胶囊，`surface` 底。
- 不用高饱和实心药丸。

### Table

- 容器 `rounded-xl` 白底 1px 边；表头 `surface` 底、12px `muted`、高 36。
- 行高 48（密集 40），1px 下划线；hover `surface`。
- 数字列 mono 右对齐，空值 `—`。
- 排序在表头文字内用小三角，不加按钮外框。

### Tabs

- 分段控件：外层 `surface` 圆角 8，内层选中项白底 + 1px 边 + `shadow-sm`，**滑块用 layout 动画**（180ms）。
- 页面级 Tab 也可用下划线样式，但同一产品只用一种。

### Dialog

- 14px 圆角，白底，1px 边，浮层阴影。
- 头部：可选 eyebrow + 18px 标题 + 13px 说明；底部按钮右对齐（白底次按钮 + 深蓝主按钮）。
- 移动端左右 16，内容区滚动，底部操作始终可见。

### 壳（顶部 header + 侧栏）

- Header 56 高，白底、下边框 1px；左侧顺序固定：**logo → 折叠按钮 → 1px 竖分隔 → 面包屑**。
- 折叠按钮 32×32，图标随状态翻转；折叠后侧栏 64 宽，只留图标。
- 面包屑：`后台 / 线路 / 服务器`，分隔符 `muted`，当前页 `ink`；移动端只留当前页。
- 侧栏按域分组：**资源**（概览/服务器/节点/中转）、**分发**（订阅/用户）、**系统**（监控/设置）；组标题 11px `muted`。
- 侧栏 `surface`，右侧 1px 线；菜单项 36 高、8px 圆角。
- 选中：`primary-soft` 底 + `primary` 文字/图标；**选中块随路由滑动**（layout 180ms）。
- 未选中：`muted`；hover `surface`。图标 16px、`stroke-width 1.5`。

### 导航（移动）

- 底部 5 项，白底 + 顶部 1px 线，无阴影。
- 选中：深蓝图标/文字 + 顶部 2px 短轨。

### 指标卡

- 4 张卡，`rounded-xl` 白底 1px 边，`p-4`；标签 12px `muted`，数字 24px mono，趋势 12px。
- 卡片之间 `gap-3`；移动端 2×2。
- 不做彩色底、不做渐变。

### 图表

- 线宽 1.5；网格仅水平、`hairline`、虚线 3 3。
- 坐标轴 11px mono `muted`；图例 6px 圆点 + 12px 文字。
- 面积填充 ≤8%；不做渐变。
- 阈值线 1px 虚线；异常区间浅红底（≤8%）。

## 6. 动效（一点灵动）

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 进入、滑动 |
| `--dur-micro` | 90ms | 按压 |
| `--dur-fast` | 140ms | hover、颜色 |
| `--dur-base` | 180ms | 选中块、Tab 滑块 |
| `--dur-dialog` | 200ms | 弹窗进入（退出 140ms） |

四个时刻：

1. **侧栏选中块**随路由滑动（layout，180ms）。
2. **Tab 滑块**移动（180ms），不是淡入。
3. **表格行 hover**：箭头右移 2px，底色 `surface`，140ms。
4. **弹窗**：`opacity + scale .98→1`，200ms。

禁止：整页 fade、逐项弹跳、数字滚动、发光/渐变 hover；全部尊重 `prefers-reduced-motion`。

## 7. 页面模板

```
┌ 侧栏 ─┬──────────────────────────────────────────┐
│      │  SERVERS / 01                  [深蓝主操作] │
│      │  服务器                                     │
│      │  装了 agent 的机器…                          │
│      ├──────────────────────────────────────────┤
│      │  ┌在线 6/6┐ ┌待处理 2┐ ┌延迟 45ms┐ ┌流量 489G┐│
│      ├──────────────────────────────────────────┤
│      │  [搜索………………]  [筛选]        [列表|卡片]    │
│      ├──────────────────────────────────────────┤
│      │  名称          状态     延迟      操作       │
│      │  香港 HKT      ● 在线   54 ms     ⋯         │
│      └──────────────────────────────────────────┘
```

- 顶部 header：logo、折叠按钮、`|`、面包屑；页面标题区仍是 eyebrow + 标题 + 说明。
- 标题区：eyebrow（拉丁，可选）+ 标题 + 一句说明；操作在右上。
- 列表页：指标卡（可选）→ 工具栏 → 表格容器 → 分页。
- 详情页：标题 + 状态徽章 + 2–4 列事实（label 11 / value 14），分区用 1px 线，不堆卡片。

## 8. 响应式

- 断点：375 / 768 / 1024 / 1440。
- 移动端：底部 5 项；列表变单列；工具栏折行；弹窗全宽左右 16。
- 320：无横向滚动、数字与标签不重叠、按钮不换行。
- 桌面内容最大宽 1440。
