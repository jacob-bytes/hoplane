# Hoplane 视觉方向 v2 · 「仪器」

> 替代 v1 的"通用 shadcn"规则。v2 的目标是：**克制、去模板感、有一点点灵动**。
> Token 以本文为准，落地时写进 `src/styles/globals.css` / `tailwind-theme.pcss`。

## 0. 为什么现在"有 AI 味"

不是颜色不好看，而是这些**模板信号**堆在一起：

| 信号 | 现状 |
|---|---|
| 大蓝主按钮 | 每页一个 `#1d4ed8` 实心按钮，和无数 SaaS 模板一样 |
| 全圆角 | 卡片 12px、按钮 8px、徽章全圆，所有东西都"软" |
| 药丸泛滥 | 状态、线路、延迟、数量全是 `rounded-full` |
| 卡片套卡片 | 灰底 + 白卡 + `shadow-sm` + `rounded-xl` 三件套 |
| 彩色图标砖 | 每个入口一个浅色圆角方块 + 彩色 lucide 图标 |
| 图表配色 | 蓝/青/紫/红，标准 dashboard 调色板 |
| 没有排版 | 标题、正文、meta 全靠 14px，层级只靠颜色深浅 |

v2 的做法是**反着来**：把界面还原成一台仪器——纸、墨、细线、数字。

## 1. 三个关键词

1. **仪器感（Instrument）**：信息密度高、对齐严格、数字等宽、装饰为零。
2. **纸与墨（Paper & Ink）**：暖白纸底、近黑墨色；主操作是"墨"，不是"品牌蓝"。
3. **一点灵动（Alive）**：只在**状态变化**处动——下划线滑动、导航轨生长、行悬停时箭头轻移。不做入场大动画、不做渐变光晕。

## 2. 颜色

主色不再是蓝色按钮。**主操作 = 墨色**；**信号色（靛）只用于焦点、链接、选中态**。

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--canvas` | `#f4f2ed` | `#0e0e0c` | 页面底（暖纸 / 暖黑） |
| `--surface` | `#fbfaf7` | `#151512` | 卡片、表格、侧栏 |
| `--raised` | `#ffffff` | `#1b1b17` | 弹窗、下拉、输入框 |
| `--ink` | `#171614` | `#ece9e1` | 主文字、主按钮底 |
| `--ink-2` | `#4a4843` | `#b9b5aa` | 次级文字 |
| `--muted` | `#6f6c64` | `#8a867c` | 说明、表头、单位 |
| `--hairline` | `#e2ded4` | `#2a2923` | 1px 分隔线、卡片描边 |
| `--hairline-strong` | `#d3cec1` | `#3a3830` | hover / 输入框描边 |
| `--signal` | `#2b4a6f` | `#8fb0d6` | 焦点环、链接、选中、图表主序列 |
| `--success` | `#2f6b4f` | `#6fbf98` | 在线、成功 |
| `--warning` | `#8a5a1a` | `#d9a35a` | 偏高、待处理 |
| `--danger` | `#a8332a` | `#e07a6f` | 异常、删除 |

规则：

- **不使用纯黑/纯白**（`#000` / `#fff` 只允许出现在主按钮前景这类极值处）。
- **大面积不用色**：颜色只出现在 1px 边、6–10% 底色、小圆点和文字上。
- 状态不能只靠颜色：必须"点 + 文字"。
- 图表 6 色（印刷感、低饱和）：`#2b4a6f`、`#3f6f6a`、`#a8763a`、`#7a5a86`、`#4f6b3a`、`#8a4b45`。

## 3. 字体

- UI：**Geist**；数据/编号/IP/延迟：**Geist Mono**，`tabular-nums`。
- 中文回退：`PingFang SC` / `Noto Sans SC`。
- 不用衬线体；全大写只允许出现在 11px 标签（`0.08em` 字距）。

| 层级 | 字号/行高 | 字重 | 用法 |
|---|---|---|---|
| 页面标题 | 22 / 30，`-0.01em` | 600 | 每页一个 |
| 区块标题 | 15 / 22 | 500 | 卡片、弹窗 |
| 正文 | 14 / 21 | 400 | 表格、按钮、输入 |
| 次要 | 13 / 19 | 400 | 说明、meta |
| 标签 | 11 / 16，`0.08em` 字距 | 500 | 表头、eyebrow（仅拉丁/数字） |
| 数字 | 13 / 18 mono | 500 | 指标、延迟、流量 |

规则：

- 一屏最多 4 种字号（标题、区块、正文、辅助）。
- 中文标签不做 `uppercase`、不加字距；`0.08em` 只给拉丁小标签。
- 单位永远比数字小一号、用 `--muted`：`54 ms`、`1.2 GB`。
- 长数字右对齐，单位不参与对齐。

## 4. 间距、圆角、线

- 间距只用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。
- 圆角只用三档：**4**（输入、徽章）、**6**（按钮、卡片）、**10**（弹窗）。禁止 `rounded-full`，唯一例外是计数器和头像。
- 卡片：`surface` + 1px `hairline`，**无阴影**。
- 浮层：1px `hairline` + 一层软阴影 `0 8px 24px -16px rgb(0 0 0 / .35)`。
- 分隔优先用线，而不是留白或底色块。

| 场景 | 值 |
|---|---|
| 页面内边距 | 桌面 24，移动 16 |
| 区块间距 | 32 |
| 卡片内边距 | 16 |
| 表格行高 | 密集 36 / 常规 44 |
| 控件高度 | 32（sm）/ 36（默认）/ 40（lg） |
| 触控目标 | ≥ 24×24，移动端主操作 ≥ 44 |

## 5. 组件语言

### Button

- 默认：**墨底纸字**（`ink` / `canvas`），6px 圆角，无阴影，高度 36。
- 次要：透明底 + 1px hairline；hover 只改边色和文字。
- 危险：`danger` 文字 + hairline，**不是红底**（红底只给确认弹窗的最终按钮）。
- 按压缩放 `0.985`，90ms；不使用阴影变化。
- 一屏一个墨色按钮。

### Chip / Badge

- 方形 4px 圆角，1px hairline，透明底；状态用 6px 圆点 + 文字。
- 只有**计数**允许全圆（如 `12`）。
- 不用彩色填充药丸表达状态。

### Table

- 无外框卡片感：表头 11px 标签 + 1px 下划线，行与行 1px hairline。
- 数字列 mono 右对齐；空值 `—`。
- hover：行底 `surface` → `#f0ede6`（暗色 `#1a1a16`），不加缩放。
- 排序箭头用 8px 三角，不用胶囊按钮。

### Tabs

- 文字 + 1px 下划线；选中下划线**滑动**（spring，见动效）。
- 不用灰底胶囊 TabsList。

### Dialog

- 10px 圆角，`raised` 底，1px hairline。
- 头部：11px eyebrow（可选）+ 18px 标题 + 13px 说明。
- 底部按钮右对齐：次要（ghost）+ 主（墨）。
- 危险确认：标题直述后果，最终按钮 `danger` 底。

### 导航（桌面）

- 侧栏 `surface`，右侧 1px hairline；无卡片、无圆角高亮块。
- 选中：左侧 2px 墨色竖轨（从中心生长 160ms）+ 文字变墨色；其余 `muted`。
- 图标 16px、`stroke-width 1.5`，与文字同色。

### 导航（移动）

- 底部栏最多 5 项；顶部 1px hairline，无阴影。
- 选中：图标/文字变墨色 + 顶部 2px 短轨；不用填充背景。

### 指标条（替代 KPI 卡片）

- 一行 4 格，用 1px 竖线分隔，不套 4 张卡片。
- 标签 11px `muted`，数字 22px mono，单位 12px `muted`。
- 需要趋势时，在数字右侧放 12px 的 `↑ 4%`，颜色只用于涨跌。

### 图表

- 线宽 1.25；网格只保留水平、`hairline`、虚线 2 4。
- 坐标轴 11px mono `muted`；图例用 6px 圆点 + 文字，不用色块。
- 面积填充最大 6%；不做渐变。
- 阈值线 1px 虚线 + 10px 说明。

## 6. 动效（"一点灵动"）

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | 进入、展开 |
| `--ease-in-out` | `cubic-bezier(.4,0,.2,1)` | 位移 |
| `--dur-micro` | 90ms | 按压、图标切换 |
| `--dur-fast` | 140ms | hover、颜色 |
| `--dur-base` | 200ms | 弹窗、页面进入 |
| `--spring` | stiffness 420 / damping 38 | 下划线、导航轨 |

四个允许的"灵动"时刻：

1. **Tab 下划线滑动**（layout spring），不是淡入淡出。
2. **导航选中轨**从中心 `scaleY(0)→1`，160ms。
3. **列表行 hover**：箭头右移 2px，hairline 变深，140ms。
4. **弹窗进入**：`opacity 0→1` + `scale .98→1`，200ms；退出 140ms。

禁止：

- 整页 fade-in 超过 200ms、列表逐项弹跳、数字滚动动画、发光/渐变 hover。
- 所有动效必须包在 `prefers-reduced-motion` 判断里。

## 7. 页面模板

```
┌ 侧栏 ─┬──────────────────────────────────────────┐
│      │  SERVERS / 01                  [墨色主操作] │  ← eyebrow + 标题
│      │  服务器                                     │
│      │  装了 agent 的机器…                          │
│      ├──────────────────────────────────────────┤
│      │  在线 6   待处理 2   延迟 45ms   流量 489G   │  ← 指标条（竖线分隔）
│      ├──────────────────────────────────────────┤
│      │  [搜索………………]  [筛选]        [列表|卡片]    │
│      ├──────────────────────────────────────────┤
│      │  名称          状态    延迟      操作       │  ← 表头 11px
│      │  香港 HKT      ● 在线  54 ms     ⋯         │
│      └──────────────────────────────────────────┘
```

- 标题区不是"标题 + 说明 + 右侧蓝色按钮"三件套，而是 **eyebrow（可选）+ 标题 + 说明**，操作放在标题同一行的最右。
- 列表页必须有：指标条（可选）、工具栏、表头、空/加载/错误三态。
- 详情页：标题 + 状态 chip + 2–4 列事实（label 11 / value 14），分区用 1px 线，不用卡片堆叠。

## 8. 响应式

- 断点：375 / 768 / 1024 / 1440。
- 移动端：底部 5 项导航；列表变单列行；工具栏允许折行；弹窗全宽（左右 16）。
- 320px 必须无横向滚动、文字不逐字换行、数字不与标签重叠。
- 桌面最大内容宽 1440，超过后居中留白。
